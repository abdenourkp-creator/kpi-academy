## Status definitions

- **RESEARCHED:** candidate/source identified.
- **VERIFIED:** source and usage rights reviewed for the specific asset.
- **DOWNLOADED:** binary/source file exists in the repository.
- **OPTIMIZED:** checked and prepared for web delivery.
- **REGISTERED:** record exists in `data/visual-assets.json`.
- **INTEGRATED:** rendered in a live application screen/lesson and verified.

## External source policy

- Unsplash: broad free commercial-use license; review depicted people, logos, artwork, and property rights per image.
- Pexels: free commercial use under Pexels License; avoid standalone redistribution and implied endorsement; review third-party rights.
- Wikimedia Commons: each file has its own license and attribution requirements; verify the file description page.
- Openverse: use the specific source record and verify the original license and attribution before downloading.

No external photograph is marked VERIFIED or DOWNLOADED in this release. This is intentional: no specific image record has yet passed an individual rights and source audit.
